# AtmoNex LLC website

Static, responsive website for scientific computing, AI agents, physics simulation, and atmospheric/environmental modeling services.

## Local preview

From the repository directory, run `python -m http.server 4180 --bind 127.0.0.1` and open <http://127.0.0.1:4180/>. No build step, package installation, API key, or backend is required. The site is compatible with GitHub Pages.

## Editing

- `index.html`: English content, capabilities, contact details, business information, and commercial terms.
- `styles.css`: layout, colors, typography, and responsive states.
- `script.js`: mobile navigation, capability deep links, email clipboard feedback, and copyright year.
- `assets/`: bundled imagery, font, brand assets, and licenses. See [ASSETS.md](ASSETS.md).

All contact actions use the existing business email. The site does not collect form submissions or automatically send messages. Native capability disclosure controls remain usable without JavaScript. JavaScript adds navigation and convenience behaviors.

The redesign follows the selected dark city-airflow direction, with AI workflows and digital twins below the hero. Existing business and commercial-terms text is retained. Illustrations are explicitly conceptual, not evidence of measured simulations or completed client projects.

See [design-qa.md](design-qa.md) for review evidence and browser validation scope. Publishing this branch requires the normal repository review and merge process.
